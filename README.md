# Grappling Hook: Neo

This is a NeoForge fork of the [Grappling Hook mod](https://www.curseforge.com/minecraft/mc-mods/grappling-hook-mod), a Minecraft mod which adds grappling hooks. The aim of this mod is to provide a fun way to get around large builds like cities.

This mod is for NeoForge 1.21.1 only. Fabric will not be supported.
